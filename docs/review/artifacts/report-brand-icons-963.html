Review artifact · #963 · brand icon set

The icons fill their box, and round at the app's corner

“can you card the AlignSynch icons to fill the icon bounds, and to have the same corner radius as the app? … each time I ask the results break something else or revert to something visually incorrect.”

The app mark's corner is now 64 px of the 512-unit canvas (12.5 %), derived from --radius ÷ the 40 px tile components/layout/footer.tsx draws — i.e. the same 5 px corner the app paints, at every size. Before it was 0.2 of the canvas: 102.4 px here and 6.4 px in a 32 px tab, a corner the app has never drawn.

Every number below is measured from the shipped bytes by alphaBBox / contrastBBox — the same two functions the gate's own ink test uses — with “before” read out of git at origin/main and “after” from the working tree.

4 · The gate, and the drift it now catches

A typed 0.2 beside a token nobody compared it to is not a value bug, it is a missing derivation. APP_RADIUS_FRACTION is now appRadiusPx() / APP_MARK_TILE_PX, read from app/globals.css at import, and tests/brand-icon.test.ts reads the sheet itself and compares it with the radius baked into the shipped file. Putting the decimal back and regenerating fails the test step by name, verbatim:

# reproduce: put a literal 0.2 back in lib/brand-radius.ts, pnpm brand:icons, npx vitest run tests/brand-icon.test.ts

 FAIL  tests/brand-icon.test.ts > the generated icon set > rounds the app mark at the app's own `--radius`, read from the sheet
AssertionError: quizhub-icon.svg rounds at 102.4 of 512; 5px on a 40px tile is 64: expected 102.4 to be close to 64, received difference is 38.400000000000006, but expected 0.05
 ❯ tests/brand-icon.test.ts:348:7

 Test Files  1 failed (1)
      Tests  1 failed | 12 passed (13)

And retyping the decimal without regenerating fails data:check by path, before any test runs — the two states are different failures and both are caught:

✗ brand icon: public/brand/quizhub-icon.svg is stale (or missing) — run: node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --import ./scripts/ts-modules.mjs scripts/gen-brand-icons.mjs

Restore the derivation, pnpm brand:icons, and both are green again — the transcript below is the shipped state.

pnpm data:check — green, 793 cases bash scripts/verify.sh — green, lane=code

5 · What did not move

public/brand/alignsynch-mark-1024.png (the mark itself) and public/brand/as2-logo_v2_cl.png are byte-identical — only the placement of the mark changed, which is the half of the owner's rule that matters. No token moved: the icons met --radius, the app did not bend to the icons. The maskable ground is still transparent — no field was added to fake a larger fill.
