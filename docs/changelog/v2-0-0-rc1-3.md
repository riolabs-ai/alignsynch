# v2.0.0-rc1.3 — the pool where each seat reads its own truth

Ten surfaces landed between `v2.0.0-rc1.2` and this candidate, and none of them is a new
destination. Every one of them answers the same question from a different seat: **what does this
person actually see, and is the sentence they read true for them?** That is why they ship as one
window rather than ten releases. A state change nobody can reach is a state that does not exist; a
notice written for the person who paid is a lie told to the person who was invited; and a catalogue
of three plans when the product sells one is a page arguing with its own checkout.

The three movements, in the order a reader meets them: **the relationship's states are readable
from the seat you are sitting in** (`#1223`, `#1224`), **every notification is worded for its
reader** (`#1227`, `#1228`, `#1225`, `#1231`), and **the catalogue is one plan** (`#1237`,
`#1241`). The two drawn screens (`#1226`, `#1232`) are the pool's evidence that a failure and an
operator's rights are states with a shape, not a JSON body and a checkbox.

## The states, from the seat you are sitting in

`lib/flow/answer-gate.ts` named four states and returned three. `"lapsed"` sat in
`ANSWER_SHEET_STATES` with a docstring claiming it outranked everything, and no branch ever returned
it — so the paused surface was authored, unreachable and untested by anybody who walked the flow.
`#1223` adds the branch between `coach` and `readonly`.

It deliberately does **not** decide whether the form exists. `action` is the same `maySubmit()` the
`sheet` branch calls, because a lapse closes the Gap, not the pairing: answers stay writable while
the answers are paused. The paused pane draws above the sheet instead of replacing it, which is the
one place this build intentionally goes further than the prototype — the prototype has no writable
lapsed state, and this one does.

`#1224` is the same defect in words rather than in branches. The relationship detail printed **one**
sentence to **both** people, and that sentence named the 14-day trial and a payment to the person who
was invited — someone who bought nothing and was never asked to. `lapseSentenceOf()` now returns two
lines, split by seat, and the Counterparty's carries no price, trial, card, payment, plan or
membership word whatever the reason was.

## Every notice in the reader's terms

Four copy changes, and each is a sentence that was true for one seat and false for the other.

- `#1227` — the Counterparty Joined email announced "Your 7 days free start today" to everybody,
  a paid plan included, because the sentence lived in the editable body and nothing could choose. It
  now says it only on a free trial, and stops calling the way in "the session" — the retired noun.
- `#1228` — the AlignSynch FAQ answered "How do I get started?" with the v1 path: register at
  `/register`, then one submission that wrote the session and its invitation together. The flow has
  been five stages since `#825`, and the answer now names them.
- `#1225` — the Counterparty's Relationship Expired body told the invited person the payment did not
  go through and the initiator's membership ended with it — billing detail that seat never sees. It
  now carries only the two blocks the copy spec names.
- `#1231` — ten labels and two headings on `/admin/email-templates` move to the Title Case the
  bundle 09 label spec prescribes, so the admin list and the document a reader searches for use the
  same words.

## One plan

`#1237` removed Family and `#1241` narrowed the catalogue to a single card: **Basic, `$9.99` a
month, one relationship.** Both changes read production before touching anything — 9
`billing_subscription` rows, all `basic/month` (4 active, 5 trialing), **0** at the `principal` tier
and **0** at interval `year` — so no subscriber is grandfathered and nothing moved on the provider.
The dormant rows stay exactly where they were, because repricing or deleting a delisted plan is a
provider-side act, not a fixture edit.

![`/pricing` at 1440 CSS px on this release's own tree (BRAND=alignsynch), signed out: one plan card — Basic, $9.99 a month, one relationship — where three cards sat before #1237 and #1241](../qa/release-2.0.0-rc1.3/pricing-1440.png)

The still is this branch's dev server, `/pricing`, 1440 CSS px, the AlignSynch brand, no session (the
route is public, so the signed-out render is the honest one for a page a visitor decides from).
`docs/qa/release-2.0.0-rc1.3/capture-pricing.mjs` is the capture, re-runnable: it asserts the page's
own words and the resolved styles before the shutter, including the brand — QuizHub's `/pricing`
carries the same `Basic` and `$9.99`, so a still of the template would pass a price check and show
the wrong product.

## Two screens that were errors and are now states

`#1226` — `POST /assessment/new` answered every unnameable throw as a named JSON 500. That is the
right answer for a `curl` and the wrong one for a person: a browser form post printed
`{"code":"create-failed","sqlstate":"42703",…}` in the window. A request whose `Accept` carries
`text/html` is now answered `303 → /assessment/new/failed`, and the screen is the bundle's
`create-failed.html` — an icon chip, "Couldn't Create This Draft", "Try Again Shortly.", and two
actions. **Try Again** reopens the stage that failed; the draft is still in the cookie, so the review
card comes back. Every other caller keeps the JSON body it reads today, byte for byte.

`#1232` — the CRUD matrix at `/admin/permissions` drew a bare checkbox per cell, which said
"granted" and "denied" in the same glyph at a glance. It now reads as **icon plus word**, and the
matrix is a table of states a reader can audit rather than a grid of ticks. The seat is
admin-gated, and production still has no `ADMIN_EMAILS` identity (`#1202`, open), so this is a
screenshot the atlas cannot take and the entry says so under **Known limits**.

## What the rest of the window is

- `#1233` — bundle 11's settings page drops the Notifications card, because the app stores no
  notification preference (`user_profile` is handle, display name, bio and country) and `/settings`
  has shipped without that card since `#164`/`#1136`. QA comparing against the bundle was flagging
  the right page as wrong.
- `#1234` — the record's gate block names the lane it asked for, so a `○ … skipped` line and a
  failure can no longer be read as the same thing in a log.
