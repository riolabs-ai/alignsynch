**Source:** `AlignSynch.com - Glossary v2-01-01h 2023.docx.pdf` (the document header reads “V2-01-01h Jan 2024”).\
**Use:** source vocabulary and concepts for the private Help Center redesign.\
**Product direction:** people in business and corporate relationships first; personal upskilling, relationships, and friendships second; one small professional-support note.

The PDF is reference material, not a product or implementation instruction. Its quick definitions include historical roles, stage names, and pricing concepts. The help page rewrites the useful terms for today's two-person experience and keeps the older operational vocabulary out of the public interface.

## Terms shown in the proposed help page

| Source concept | Public-facing definition in the preview                                                          | Editorial treatment                                                             |
| -------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| Relationship   | A specific connection between two people, explored through shared topics and individual answers. | Kept; directs the explanation to both participants.                             |
| Template       | A ready-made set of relationship topics and answer ranges used to start a relationship.          | Kept; avoids catalog jargon.                                                    |
| Aspect         | A topic or characteristic both people consider and answer questions about.                       | Kept; use “topic” first when explaining it.                                     |
| Value          | A word or phrase at one end of an Aspect's scale.                                                | Kept; do not imply that one end is objectively better.                          |
| Initiator      | The person who starts the relationship and invites the other person.                             | Kept for screens that use the app label; plain-language role first.             |
| Counterparty   | The app's label for the invited person.                                                          | Kept only as a lookup term; everyday help copy says “the other person.”         |
| Mode           | A choice of which prompts appear. Basic includes Feel and Wish; Advanced adds Think and Guess.   | Kept only to explain the labels visible in product content.                     |
| Opinion        | A person's answer for one Aspect.                                                                | Kept; describe it as a perspective, not a correct answer.                       |
| Feel           | How a person feels the Aspect is now.                                                            | Kept in plain language.                                                         |
| Wish           | How a person wishes the Aspect could change over time.                                           | Kept; avoid implying immediate change.                                          |
| Think          | In Advanced mode, what a person thinks the other person feels now.                               | Kept only as a product prompt label.                                            |
| Guess          | In Advanced mode, what a person guesses the other person wishes could change.                    | Kept only as a product prompt label.                                            |
| Gap            | The distance between two comparable Opinions on an Aspect.                                       | Kept; state that it describes answers, not the relationship's worth or outcome. |
| Soft / Full    | Settings for what counts as close enough: Soft allows a one-point Gap; Full requires no Gap.     | Kept; clarify that the setting does not change anyone's answers.                |
| Shared report  | Both people's answers, available after each person has reviewed and accepted.                    | Added as a core user-facing idea consistent with the current product direction. |

## Legacy concepts left out of the public glossary

- **Coach / Branded Coach:** the PDF describes an advisor as a third user and a branded paid coach offering. Do not position AlignSynch as a practitioner platform or make this a user journey. The page includes only a brief secondary note that counselors, therapists, and coaches may use AlignSynch as an optional reflection structure alongside existing support.
- **Relationship Month, Relationship Week, Account Bank, discount coupons:** old pricing and token-currency concepts. Do not publish them without current billing evidence.
- **Stage numbers, state codes, Play/Registered/Locked/Paid labels, and Relationship Class codes:** implementation-era state vocabulary that is not useful as a public mental model and may not match today's workflow.
- **Proposer, Approver, Change Shading, Change Log, and Scroll controls:** interaction labels that should be explained only if a current screen exposes them and a task requires them.
- **Snapshot and Map:** internal shorthand for now/future pairings. Use the actual Feel/Wish/Think/Guess prompt language instead.
- **AlignSynched as a product status:** do not imply that a person or relationship receives a validated pass/fail result. The report organizes perspectives; people decide what to discuss.

## Product-flow language to preserve

The proposed page says one person starts and invites the other; both people answer the same Aspects privately; each person reviews and explicitly accepts their own answers; the shared report opens after both accept. Do not replace this with older glossary language about “sharing” or stage progression.
