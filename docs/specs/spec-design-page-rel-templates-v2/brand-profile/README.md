Private, local-only working bundle for the AlignSynch company/app profile and audience direction.

- Open `brand-and-audience-profile.html` to review the responsive, browser-ready profile page.
- `css/brand-and-audience-profile.css` contains the page styling.
- `images/alignsynch-logo.png` uses the approved AlignSynch lockup.
- `AUDIENCE-AND-POSITIONING.md` is kept here so the profile folder can be shared on its own. The canonical V2 copy source is `../AUDIENCE-AND-POSITIONING.md`, an out-of-tree handoff held outside this repository.

## Audience order

1. Business and corporate relationships.
2. Personal growth, personal relationships, and friendships.
3. A small supporting callout for counselors, therapists, and coaches.

The page is visibly labeled as a private draft and includes `noindex,nofollow,noarchive`. Its primary CTA links to the local home-page template section. Nothing here has been published or wired into the live application.

Product mechanics follow the AlignSynch Project Brief dated 4 Nov 2026: two people answer the same Aspects privately; each reviews and explicitly accepts; the shared report opens after both accept. Public positioning is direct to the people in those relationships and does not describe AlignSynch as a practitioner platform.
