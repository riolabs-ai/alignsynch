The static prototype uses local files so the preview does not depend on third-party hosts, apart from the Tailwind CDN and Google Fonts. This record says where each file came from so it can be traced or replaced.

| Local file | Use in page | Source |
| --- | --- | --- |
| `images/alignsynch-icon.png` | Header mark, favicon, sidebar | Prototype asset `alignsynch-icon.png`. The app's canonical brand lockup is `public/brand/as2-logo_v2_cl.png` via `data/media.ts`; use the registry, not this copy. |
| `images/alignsynch-logo.png` | Full lockup (reference only; not referenced by the HTML) | Prototype asset `alignsynch-logo.png`, same origin as the home bundle's logo. |
| `css/tokens.css` | `:root` tokens for `BRAND=alignsynch` | Prototype `assets/tokens.css` (pass 10, design notes v3.3 §16–19, §33, §46). Ports into `app/globals.css`. |
| `js/tw-config.js` | Tailwind CDN theme | Prototype `assets/tw-config.js`: QuizHub `tailwind.config.ts` (colors, radius, screens) plus the v2 tokens. Ports into `tailwind.config.ts`. |
| `js/proto.js` | Preview shell behaviour | Prototype `assets/proto.js`, with page links re-pointed at sibling bundles. Not shipped. |
| `js/crud-matrix.json` | Matrix snapshot (also inlined in the HTML) | Generated by `src/matrix_data.py` from `crud-matrix.md` (pass 10 counts). The product parses `docs/specs/v2-prototype/crud-matrix.md` at request time; do not hand-copy the rows into a component. |
| `js/crud-matrix.js` | Preview render and URL filters | Prototype `assets/crud-matrix.js`. Rebuild in React; do not ship the file. |
| `admin-crud-matrix.html` | Page | Generated by the prototype build (`src/build.py`, `src/admin.py`); links and asset paths rewritten to be local and relative. |
| `reference/*.png` (6 files) | Approved renders | Headless Chrome renders from the prototype QA (`src/qa/check4.js`) at 390 and 1280 px. File name = state (`admin-crud-matrix`, `-filtered`, `-broken`). |
| Tailwind CSS `3.4.17` | Utility CSS at runtime | `https://cdn.tailwindcss.com/3.4.17` (preview only; the app compiles Tailwind). |
| Inter 400/500/600/700 | Body and headings | Google Fonts (preview only; use the app's font setup). |

No photography or third-party imagery is used in this bundle, so there are no licences or credits to record. The matrix rows and the P0 / conflict copy are the triage source, not fixture names.
