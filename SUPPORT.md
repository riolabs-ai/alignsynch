# Support

## Read the docs

Start with [`docs/README.md`](docs/README.md) — it is the hub: every document
under `docs/`, listed once, grouped by the question it answers.

## Ask a question or discuss

Use GitHub Discussions on this repository:
https://github.com/riolabs-ai/alignsynch/discussions

## Report a bug

Open an issue using the **Bug report** template:
https://github.com/riolabs-ai/alignsynch/issues/new?template=bug.md

## Report a vulnerability

See [`SECURITY.md`](SECURITY.md). Vulnerabilities are reported privately, never
as a public issue.
